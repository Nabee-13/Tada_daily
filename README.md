# 쨔뿌러지는일과 (일정 + 메모 + 가계부)

## 열어보기
`index.html`을 더블클릭하면 브라우저에서 바로 열려요. (서버 필요 없음)
데이터는 브라우저 localStorage에 저장돼요. 파일 주소(주소창)가 바뀌면 다른 저장소로 취급돼요.

## 파일 구조 (C 프로젝트처럼)
- index.html : 화면 뼈대(HTML)와 파일 연결 (`<script src>` 순서 = 링크 순서)
- css/style.css : 모양(색, 간격, 배치)
- js/state.js : 전역 데이터 db, 저장/불러오기 (맨 먼저 로드)
- js/utils.js : 시간 변환, 색칠 계산, DOM 도우미, 통계 그래프
- js/tags.js : 태그 탭, 태그 팝업
- js/colorpicker.js : 색 선택기
- js/daily.js : 일간(체크리스트, 시간표), 할 일 수정, 일기
- js/views.js : 주간, 월간, 체크리스트
- js/money.js : 가계부, 예산, 캘린더
- js/theme.js : 색 테마, 상단 이미지, 기기별 기본 배치, 달력 위젯, 설정 팝업
- js/blocks.js : 블록 위젯 배치, 메모장, 오늘의 가계부
- js/app.js : render(), 날짜 이동, 버튼 연결, 시작 (맨 마지막 로드)

## 참고
- 모듈(import/export)을 쓰지 않아서 모든 함수와 변수가 전역(global)이에요. C의 전역 변수/extern과 비슷해요.
- 새 파일을 만들면 index.html의 `<script>` 목록에 추가해야 해요. 순서가 중요해요: state.js가 먼저, app.js가 마지막.
- 기능을 고칠 때는 위 구조에서 해당 파일만 열면 돼요.

## 새로 생긴 것
- 설정(⚙): 배경/카드/글자/강조색을 직접 고르고 자동 저장, 상단 이미지 올리기
- 위젯 배치는 폰과 PC가 따로 저장돼요 (db.layouts.pc / db.layouts.phone)
- 위젯 구역: T(위 전체폭) / L(왼쪽) / R(오른쪽). 블록 편집에서 구역을 바꿔요.
- 주석: 각 함수 바로 위에 한 줄 설명이 있어요. 데이터 구조 설명은 js/state.js 맨 위.

## 더 새로 생긴 것
- 주간/월간도 위젯 화면이에요. 블록 편집으로 구역·순서를 바꾸고, 배치는 화면(일/주/월)과 기기(폰/PC)마다 따로 저장돼요.
- 주간: 주차 달력(1주차, 2주차…) / 월간: 월 선택(1월~12월, 연도 ‹ ›)
- 설정(⚙): 태그 관리와 꾸미기 프리셋(색 + 이미지, 최대 5개)
- 상단 날짜 이동줄과 태그 탭은 숨겼어요 (CSS의 `.nav,.tagbar{display:none}`). 지우면 다시 보여요.

## 탭별 색 / 프리셋
- ⚙ 설정 → "모든 탭 같은 색 사용"을 끄면 일간/주간/월간/가계부 탭마다 색을 따로 정해요 (db.theme.tabs).
- 프리셋은 색 설정만 저장해요 (최대 5개, 이미지 제외). 시간표 칸 높이는 css/style.css 맨 아래 `.c{height:20px}`.

- 달력은 앞뒤 달 날짜까지 채우고(어둡게) 누르면 그 날로 이동. utils.js의 calDays()가 칸 목록을 만들어요.

- 이미지: 화면(일간/주간/월간/가계부)마다 따로, 편집 팝업에서 비율·확대·위치·너비 (theme.js의 openBanner)

- 정기 결제를 고치면 이미 입력된 기록도 같이 바뀜 (recurring.js의 syncRecurring)

- 일간 달력은 월간과 같은 칸(views.js의 calCell): 완료한 일 점 + 완료/전체. 시간표는 끌어서(터치는 시작·끝 칸 탭) 시간을 골라 할 일 추가.

## 동기화 켜기 (폰 ↔ PC)
1. supabase.com 에서 무료 프로젝트를 만들어요.
2. 왼쪽 SQL Editor → `supabase_setup.sql` 내용을 붙여넣고 Run.
3. Project Settings → API 에서 Project URL 과 publishable(anon) 키를 복사해 `js/config.js`에 붙여넣어요. (service_role 키는 절대 X)
4. (선택) Authentication → Sign In / Providers → Email 에서 "Confirm email"을 끄면 가입 즉시 로그인돼요. 켜 두면 확인 메일을 눌러야 해요.
5. 폴더 전체를 인터넷에 올려요 (GitHub Pages / Netlify / Cloudflare Pages). 폰에서도 그 주소로 열어요.
6. 앱의 ⚙ 설정 → 동기화에서 가입/로그인. 폰과 PC 모두 같은 계정으로 로그인하면 끝.
- 규칙: 마지막에 저장한 쪽이 이겨요(기기 시계 기준). 처음 만난 기기 데이터와 서버 데이터가 다르면 어느 쪽을 쓸지 물어요.
- 이미지는 용량이 커서 따로 저장되고, 바뀔 때만 올라가요. 배치(폰/PC)와 색 설정도 같이 동기화돼요.
- 파일: js/config.js(주소·키), js/sync.js(동기화 코드), supabase_setup.sql(표 만들기)
